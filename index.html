How to Install (Developer Mode)

  1. 1

    Download the Repository

    Go to the SnapStream GitHub page, click the green "Code" button, then select "Download ZIP". Extract the ZIP to a folder on your computer.

  2. 2

    Open the Extensions Page

    In Chrome or Edge, navigate to chrome://extensions in your address bar.

  3. 3

    Enable Developer Mode

    Find the "Developer mode" toggle in the top-right corner of the extensions page and turn it on.

  4. 4

    Load the Extension

    Click "Load unpacked", then select the extracted SnapStream folder (the root directory containing manifest.json). The 🎯 SnapStream icon will appear in your toolbar!
